# GanjaGate — Anti-Cheat Guard Mod for GanjaCraft

**GanjaGate** — серверный античит-мод для NeoForge 1.21.1, предназначенный для полной защиты сервера GanjaCraft от сторонних читерских модов и модифицированных клиентов.

---

## 🛡️ Принцип работы

1. **Серверная верификация**: Проверка происходит на стороне сервера в фазе подключения (`Configuration Phase`), **до** того как игрок зайдёт в мир.
2. **Невозможность обхода**:
   - Используются сообщения NeoForge Network Payload (`ConfigurationTask`).
   - На каждый запрос генерируется случайный криптографический `nonce`, исключающий повторное воспроизведение ответов (replay attacks).
   - Если клиент отключает ответ, убирает мод или присылает modId сторонних модов — сервер расторгает соединение.
3. **Авто-конфигурация**: При старте сервера мод автоматически считывает все установленные серверные моды и вносит их в `config/ganjagate.json`.

---

## 🚀 Сборка и деплой

### Сборка
Запустите `BUILD.bat` в корне репозитория `ganja_gate`.
Или выполните команду в PowerShell/CMD:
```cmd
BUILD.bat
```

Скомпилированный jar-файл будет сохранён в `build/libs/ganja-gate-1.0.0.jar` и автоматически скопирован в директорию модов локального сервера (`s:\Games\LegacyLauncher_portable\game\home\neoforge-21.1.247\mods`).

---

## ⚙️ Настройка (`config/ganjagate.json`)

После первого запуска сервера на стороне сервера появится файл `config/ganjagate.json`:

```json
{
  "strict": true,
  "auto_update_whitelist": true,
  "kick_message": "§c[GanjaGate] Обнаружены неразрешённые моды!\\n\\n§fЗапрещённые моды:\\n§e{mods}\\n\\n§7Удалите их и перезайдите.",
  "whitelist": [
    "alexsmobs",
    "apotheosis",
    "create",
    "ganjagate",
    "minecraft",
    "neoforge",
    "tacz"
  ]
}
```

- **`strict`**: `true` — принудительный кик за неразрешённые моды; `false` — только запись предупреждений в лог сервера.
- **`auto_update_whitelist`**: `true` — автоматически добавлять новые серверные моды в whitelist при запуске сервера.
- **`whitelist`**: Список разрешённых `modId` клиентов.
